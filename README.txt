InventoryWebAPI

How to run:

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

   npm install

4. Start the API:

   npm start

5. You should see:

   Inventory API running on http://localhost:3000

6. Join your Minecraft server.
7. The terminal should show the player's inventory JSON.

Important:
The API key must match the plugin key:
change-this-secret-key
